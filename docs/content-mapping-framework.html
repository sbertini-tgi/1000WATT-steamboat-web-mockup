01How to read this

The new mockup is a single, editorial homepage — a magazine-style narrative (Hero → Buyers Now → Agents → Lifestyle → Stories → How We Work → GroupGives → Search) rather than the utility-portal structure of the current site. The current site is a TRIBUS/IDX platform organized around menus of tasks (Buy, Sell, Resources, Blog); the new one is organized around a feeling and a short set of moves.

That mismatch is the whole job. This framework does three things: it gives every current content bucket a single disposition (what happens to it), it names the orphans (content the new design has no slot for), and it names the net-new content the new design invents and will need written from scratch. Use the rubric in §2 to classify any page not yet listed — it's meant to outlive this first pass.

One scope note: this inventory works at the content-bucket / navigation level (the site's information architecture), not every individual blog post or listing. Listings and posts flow through the buckets — settle the buckets first.

02The five-disposition rubric

Every piece of production content gets exactly one of these. When you find a page this document didn't list, run it through the same five questions and it lands cleanly.

Direct

There is a section on the new homepage that this content is. It moves in with light copy edits. Ask: "Does a homepage section already exist for this?"

Deeper

Belongs on a sub-page reached from the nav; the homepage only teases or links to it. Ask: "Is this a whole page the header should point to, not a homepage block?"

Transform

The information survives but must be rewritten into the new editorial voice (seasons, buyer briefs, "the valley") before it fits. Ask: "Does this need a new frame, not just a new coat of paint?"

Orphan

No slot in the current design. Requires a decision: retire it, or build a page for it. Ask: "If we shipped the mockup today, where would this literally go? Nowhere?"

Net-new

The reverse case — the new design invents this and production has nothing to fill it. It needs original content created. Ask: "Is this block empty until someone writes it?"

05Orphan report — content with no home yet

These are the decisions the mockup forces. Each is real production content (or a real function) that the new single-page design simply has no slot for. For each: a recommendation, but the call is yours.

Property search & live listings

Featured Properties · IDX · Open Houses · Sold · Account

The current homepage leads with 20 listings; the new one leads with buyers and never shows a listing. The search box is an entry point, not a results grid.

Recommend: keep the IDX (TRIBUS or successor) as a deeper "Search / Listings" experience linked from the Search section; decide whether login/saved-search survives. Confirm the buyers-not-listings inversion is intended before building.

Commercial real estate

Commercial Sale · Commercial Lease

An entire service line. The new site's voice is residential and lifestyle-led; commercial has no tone-appropriate slot.

Recommend: spin off to its own deeper page (or micro-site) linked from footer/Services — don't force it into the editorial narrative.

Our Communities

Neighborhood / area guides

Community pages are major buyer-intent and SEO assets. Lifestyle (Ski/Ride/Rest…) is thematic, not geographic, so it doesn't replace them.

Recommend: build a deeper "Communities" section; consider linking to it from Lifestyle or Search. High priority to retain.

Property management & vacation rentals

Service line

A distinct revenue/service offering with its own audience. Nothing in the mockup addresses it.

Recommend: deeper service page; decide whether it's promoted in nav/footer or treated as a separate brand.

Mortgage & Forecast

Finance utilities

Mortgage info and the market Forecast tool are utility content that clashes with the editorial tone and has no block.

Recommend: fold Mortgage into the buyer guide (Deeper); make Forecast part of a market-reports hub, or retire if low-traffic.

About Us

Company story

The brand's story survives only as fragments (Hero line, GroupGives). There's no place that tells who The Group is.

Recommend: build a deeper About page that gathers the brand statement, ownership model ("everyone owns a piece"), leadership, offices, and affiliations.

06Net-new content the design needs

The reverse gap: sections the mockup invents that production has nothing to fill. These aren't migrations — they're content that has to be written or produced before the new site can ship honestly.

Content that must be created

  • Net-new  Buyers Now — live buyer briefs. The signature idea: real, anonymized buyers with budget, story, and a representing agent. Reverse-prospecting content that has no production source. Needs a sourcing + writing + approval workflow (and the "Read the brief" / inquiry-form pipeline behind it).
  • Net-new  Season taxonomy for agents. The agent grid filters by Deep Winter / First Snow / Late Winter / Shoulder / Aspen Turn / Summer. Every broker needs season tags assigned — a new data field that doesn't exist today.
  • Net-new  Editorial voice pass. Hero line, eyebrows, "the valley" language, buyer-brief copy. The migrated content (market reports, tips, why-Steamboat) must be rewritten to match — budget for a copy/editorial pass, not just a paste.
  • Net-new  Lifestyle photography. Ski / Ride / Rest / See / Stay each need a hero-grade image. The mockup uses placeholders; production imagery likely won't match this art direction.
  • Net-new  Buyer & Seller guides. "Precision" and "Fluency" cards link to guides that don't exist as such yet — the current Buy/Sell pages are the raw material but need rewriting.

08Recommended next steps

  1. Confirm the three big inversions

    Buyers-not-listings on the homepage, flat agent grid (no leadership hierarchy), and editorial-over-utility tone. These drive every orphan decision — lock them before building deeper pages.

  2. Rule on each orphan in §5

    For Commercial, Communities, Property Mgmt, Mortgage/Forecast, About, and the IDX/account stack: decide retire vs build a deeper page. That turns this framework into a real sitemap.

  3. Stand up the deeper-page skeleton (§7)

    Create routes/stubs for the implied pages so nav links resolve and migration has a destination.

  4. Commission the net-new content (§6)

    Buyer briefs, agent season-tags, lifestyle photography, and the buyer/seller guides gate launch — start them in parallel with the migration.

  5. Migrate bucket by bucket, voice-editing as you go

    Work the matrix top to bottom. Every "Transform" row is a copy task, not a copy-paste. Keep compliance disclaimers (MLS/EHO/REALTOR®/accessibility) non-negotiable in the footer.
