About these reviews

Two notes on the set.

These come across from Testimonial Tree as written. Two things are worth naming rather than designing around.

First, more than half mention Geoff alongside Matt. If that partnership is current, the site should say so plainly — a two-person team is a selling point, and reviews that name someone the site never introduces read as an oversight. If it is historic, the reviews are still true and the copy should place them in time.

Second, none carry a submarket or a transaction side. “Bryan Swintek · Mountain Area Buyer” would prove geographic range at the same time as it proves service, at the cost of one permission request.

  • Decide whether the Geoff partnership is current, and say so
  • Add submarket and buy/sell side to each review
  • Date the older ones so the set reads as a fourteen-year record
  • Keep the short ones — “A+” is credible precisely because it is unpolished
